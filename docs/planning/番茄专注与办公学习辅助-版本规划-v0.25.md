# 番茄专注与办公学习辅助：版本规划报告（v0.25 线）

> 立项：2026-10-08。四模块独立版本线之一（0.23 天气 / 0.24 纠缠 / 0.25 番茄 / 0.26 语音），
> 用户指定实现顺序第 3 位（2026-10-08 用户拍板与纠缠对调：纠缠 0.24、番茄 0.25）。设计初稿见 wiki [设计-番茄专注与办公学习辅助](../../wiki/设计-番茄专注与办公学习辅助.md)。
> 版本线：**0.25.0 起递增，每次 commit patch +1**；版本单一源 `pet/__init__.py.__version__`，每次提版同步 README 版本沿革。
> 用户说「提交」= 只提交与 0.25 相关的改动。

---

## 1. 目标与范围

**一句话**：把吃鼠标的「强制休息」单向机制升级为「专注 ⇄ 休息」节律器——用户主动开启番茄钟，桌宠全程陪伴、到点提醒。

**本线做**：FocusSession 状态机 + 多入口 + 陪伴行为 + 养成联动 + 当日统计。
**本线不做**（后置登记）：任务清单标签、周/月统计面板、mini-swe 联动（远期脑洞）。

## 2. 现状基线（代码锚点）

| 事实 | 锚点 |
|---|---|
| 吃鼠标 Session 接口风格 | `pet/proactive.py` EatMouseSession（start/force_spit/on_dnd_active） |
| 久坐/休息提醒与静默条件 | proactive 既有链 + 活跃内容检测（视频白名单） |
| FSM 行为模式位 | `pet/behavior.py`（WANDER 为模式非 ActionType 的先例） |
| 全局热键 | `pet/hotkey_mac.py / hotkey_win.py`（v0.11） |
| 托盘菜单 | `pet/tray.py` |
| 养成数值单一真相源 | `pet/pet_state.py`（observer + 原子持久化） |
| 音效管线 | v0.19.0（默认关） |
| 原子写持久化模式 | proactive_state.json（focus_state.json 同款） |

## 4. 风险与依赖

- **独立性**：不依赖 0.23/0.24/0.26。与 0.24 纠缠的约定接口：纠缠线已按「focus 模块存在且处于 FOCUS」防御性探测静默，本线落地 FocusSession 后自动接通（0.25.3 验证）。
- 与吃鼠标并存：番茄运行中久坐/吃鼠标提醒静默（节律被接管），到期恢复——在 0.25.3 一并处理。
- 安全红线：任何状态不抑制输入；break_enforce 是唯一例外路径且默认关。
