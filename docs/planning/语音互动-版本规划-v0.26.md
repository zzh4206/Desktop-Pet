# 语音互动：版本规划报告（v0.26 线）

> 立项：2026-10-08。四模块独立版本线之一（0.23 天气 / 0.24 纠缠 / 0.25 番茄 / 0.26 语音，2026-10-08 对调原 24/25 段），
> 用户指定实现顺序第 4 位（依赖最重：平台录音权限 + ASR 模型内存）。设计初稿见 wiki [设计-语音互动](../../wiki/设计-语音互动.md)。
> 版本线：**0.26.0 起递增，每次 commit patch +1**；版本单一源 `pet/__init__.py.__version__`，每次提版同步 README 版本沿革。
> 用户说「提交」= 只提交与 0.26 相关的改动。

---

## 1. 目标与范围

**一句话**：文字聊天之上补语音双向链路——听得懂（ASR 语音输入）、会说话（TTS 播报）。

**本线做**：P0 系统 TTS 播报 + P1 按键说话（whisper.cpp 本地 ASR，云 API 备选 provider 位）。
**本线不做**（后置登记）：P2 VAD 自动唤醒、逐音素口型（动效调研已结论：不必要）、音色随阶段/心情变化。

## 2. 现状基线（代码锚点）

| 事实 | 锚点 |
|---|---|
| 聊天链路（ASR 文本直接进） | `pet/llm.py` OpenAICompatibleClient 流式 |
| 气泡显示事件（TTS 订阅点） | `pet/bubble.py` BubbleWidget |
| 全局热键 | `pet/hotkey_mac.py / hotkey_win.py`（v0.11） |
| 重模型懒加载 + 用完回收 | 情绪模型三态模式 + ORT 子进程隔离回收经验 |
| DND 检测 | 吃鼠标/proactive 共用链 |
| 权限向导先例 | v0.8（麦克风权限引导复用其模式） |
| API key 管理 | 平台密钥库 keyring（云 ASR 备选） |

## 4. 风险与依赖

- **独立性**：不依赖 0.23/0.24/0.25。与其他线的自然组合点（后置）：TTS 可朗读番茄到点提醒（0.24）、纠缠撒娇可出声（0.25）——都走 0.26.1 的订阅开关，不需要对方改动。
- 平台风险：win pyttsx3 音色质量需 Spike（0.26.0 前置验证）；whisper.cpp small 内存驻留需实测，超标则只保留「说话时拉起、说完即退」的瞬态模式。
- 麦克风权限是 mac 硬门槛：拒绝授权必须有完整降级路径（回到纯文字）。
