# 核心拆件生成稿 v1

参考：`assets/reference/young_ref.jpg`。

交付：`face_base.png`、`skirt.png`、`torso.png`，均为 1280×1284、8 bit/通道 RGBA PNG，背景透明。`layers_preview.png` 仅为灰底合层检查图，不是透明图层。

采用内置 image_gen 完成遮挡补绘及面部修正，再进行保留 alpha 的尺寸与位置校正。工具没有可用的模型版本参数，也没有返回可核验模型版本，所以不能确认或宣称使用了用户要求的 GPT Image 2.5。完整提示词保存在 `prompts.json`。

已生成内容：无虹膜、瞳孔、高光、睫毛的双眼眼白；额头和侧脸补全及短颈；无围裙、鲸鱼图案、手臂的主裙；无手掌及袖口的上身衣料。原有文件未覆盖。

验收限制：这是待精修生成稿，未通过用户要求的高精度原画保真验收。生成过程重绘了原图，裙边金色花纹、装饰结、部分褶皱、线宽和轮廓存在差异。全画布位置按可见特征近似配准，并非逐像素严格对齐。眼白形状及眉部细线仍需与独立眼睑、瞳孔图层联合检查；边缘也未经过逐像素人工精修。不能直接宣称可用于最终无缝蒙皮。

预览叠放顺序为裙子、面部、上身，使短颈位于领结后方。正式绑定时须确保短颈搭接由领口覆盖；裙腰搭接由上身覆盖。实际使用仍需原图叠层校正及变形测试。

`validation.json` 保存导出格式和位置变换信息；`export.ps1` 仅记录导出流程，依赖本机保留的生图原始结果。
